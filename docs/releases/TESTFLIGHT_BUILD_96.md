# TestFlight 1.0 (96) — 업로드 준비

2026-11-27 메모 기능과 UI 변경을 iOS·iPadOS·내장 watchOS 및 macOS에 배포한다.
이 문서는 준비 상태이며 Apple 업로드 성공이나 처리 완료를 뜻하지 않는다.

## 포함한 변경

- 새 메모는 글 메모와 체크리스트만 만든다. 그림 작성·편집·지우기는 제거하고 이전 필기는 읽기 전용으로 보존한다.
- 빈 목록의 직접 생성, 유형·고정·선택 표시, 검색 복구, 체크리스트 진행률·항목 관리·입력 포커스와 큰 글자 배치를 개선한다.
- iPad의 체크 항목 추가·분할 화면 전환에서 편집 본문이 사라지는 현상을 보완한다.
- 기존 그림을 교체하지 않는 저장 경로와 화면 전용 빈 체크 항목의 갱신 후 보존을 적용한다.
- V11 스키마, CloudKit 식별자, 백업 형식과 기존 데이터 호환은 유지한다.

프로젝트 빌드 번호 14곳과 플랫폼 Info.plist 5개를 96으로 통일하고 마케팅 버전은 1.0을 유지한다.

## 구현 검증

- 최종 공통 테스트 Debug 819개·Release 782개 통과.
- 메모 관련 Debug 36개·Release 35개 통과.
- 전체 플랫폼 회귀 게이트와 최종 iOS Debug UI·Release 빌드 통과.
- iPhone 생성·자동 저장·재실행·체크 완료·정렬·검색·삭제, 저장 실패 복구, 이전 필기 보존, 큰 글자 화면 확인.
- iPad 회전·초안 보존, 체크 항목 입력·완료·열 접기/펼치기·이전 필기 재열기 확인.
- macOS는 Debug·Release 빌드와 코드 검토까지 확인했으며 실제 창 수동 조작은 수행하지 않았다.

상세 변경과 검증 경계는 [메모 정리 기록](../plans/completed/MEMO_TEXT_CHECKLIST_SIMPLIFICATION.md)을 따른다.

## 배포 상태

소스 commit·push 후 고정 소스로 서명 archive를 만들고, 앱·위젯 총 6개 번들의 버전·서명·App Group·CloudKit 권한 및 Production 배포 패키지를 확인한 뒤 업로드한다.
업로드·Apple 처리·테스터 그룹·설치는 각각 실제 확인한 상태만 기록한다.
