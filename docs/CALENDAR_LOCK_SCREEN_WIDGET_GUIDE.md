# 오늘 캘린더 일정 잠금 화면 위젯 사용 안내

`PlanBase 오늘 일정`은 오늘에 걸쳐 있는 캘린더 일정과 전체 일정 수를 보여준다.
이 위젯이 포함된 버전을 설치한 뒤 사용할 수 있다. 현재 최적화 작업의 구현이며,
TestFlight 1.0(86)에 포함됐다는 뜻은 아니다. 배포·실제 화면 검증 상태는
[최적화 실행 결과](plans/active/OPTIMIZATION_2026_10_02_RESULTS.md)를 따른다.

## iPhone에 추가하기

1. PlanBase를 열고 캘린더에 오늘 일정이 있는지 확인한다. 앱이 위젯에 표시할 데이터를 준비한다.
2. iPhone 잠금 화면을 길게 누르고 **사용자화**를 선택한다.
3. 잠금 화면 편집에서 **위젯 추가**를 누른다.
4. PlanBase의 **PlanBase 오늘 일정**을 선택하고, 원하는 모양을 빈 자리에 추가한다.
5. 위젯 선택 목록을 닫고 **완료**를 누른다.

추가 절차는 [Apple의 잠금 화면 위젯 안내](https://support.apple.com/ko-kr/118610)를 따른다.
목록에 보이지 않으면 이 위젯이 포함된 앱 버전인지 확인하고, 앱을 한 번 연 뒤 목록을 다시 확인한다.

## 표시되는 내용

| 모양 | 표시 내용 |
|---|---|
| 한 줄 | 첫 일정의 제목·종일 또는 날짜 기간·나머지 일정 수 |
| 원형 | 오늘 전체 일정 수 |
| 직사각형 | 최대 두 일정의 제목·종일 또는 날짜 기간·전체 일정 수·나머지 수 |

날짜 단위 일정이므로 같은 날 일정은 `종일`, 여러 날 일정은 시작·종료 날짜로 표시한다.
위젯을 누르면 앱의 **오늘 캘린더**로 이동하도록 구현돼 있다. 시스템에서 잠금 해제를 요청할 수 있다.
시스템의 개인정보 숨김 상태에서는 제목·기간을 숨기고 일정 수만 표시하도록 처리한다.

## 새 일정이 바로 보이지 않을 때

위젯은 앱이 **마지막으로 성공적으로 발행한 데이터**를 표시한다. 앱을 열거나 일정 저장·동기화가
완료되면 갱신을 요청하지만, 실제 화면 갱신 시점은 시스템이 관리한다.
따라서 다른 기기의 변경이나 새 일정이 즉시 표시된다고 보장할 수 없다.
갱신 정책은 [Apple의 위젯 갱신 설명](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)을 따른다.

이전 내용이 남아 있으면 PlanBase를 열어 캘린더에서 최신 내용을 확인한 뒤 잠금 화면을 다시 확인한다.
오늘 날짜를 포함하는 발행 데이터가 없거나 읽을 수 없으면 `앱을 열어 갱신` 또는 `갱신`으로 표시한다.
`일정 없음`은 읽을 수 있는 데이터에서 오늘 일정이 0개일 때만 표시한다.
`업데이트 필요` 또는 `업데이트`가 보이면 설치된 앱이 읽을 수 없는 새 데이터 형식이므로 앱 버전을 확인한다.

## 현재 확인 범위

공통 로직·위젯 데이터 발행 테스트와 플랫폼 빌드는 통과했다. 실제 잠금 화면의 세 모양,
개인정보 숨김·탭 이동·자정 전환 및 iPad·Watch 화면 확인은 남아 있다.
이 안내와 자동 검사 통과를 실제 OS 화면 검증 완료로 간주하지 않는다.
