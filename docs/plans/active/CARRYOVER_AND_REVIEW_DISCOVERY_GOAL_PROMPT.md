PlanBase의 이월함 인지 개선, 직접 작성한 회고 모아보기, 잠금 화면 작업 선택·시작 흐름 보완을 하나의 Goal로 설정하고, 구현·디자인 점검·테스트·결과 정리까지 완료해줘. 같은 목표의 활성 Goal이 있으면 이어서 진행하고, 별도로 지정하지 않은 토큰 예산을 임의로 설정하지 마.

`/Users/home/ai_project/planbase/docs/plans/active/CARRYOVER_AND_REVIEW_DISCOVERY_PLAN.md`

잠금 화면 추가 진단과 동작 기준도 함께 따라줘.
`/Users/home/ai_project/planbase/docs/plans/active/LOCK_SCREEN_TASK_SELECTION_FOLLOWUP.md`

먼저 AGENTS.md, 계획 문서, 현재 코드와 변경 내역을 확인해. 이미 작업 트리에 있는 칸반 빈 화면과 체크리스트 기본 펼침 변경을 보존하고 그 위에서 진행해.

목표는 다음 세 가지야.

1. iPhone·iPad·Mac의 이월함에 전체 개수와 마지막 확인 이후 새로 발견한 작업을 표시해. 이월함을 확인해도 전체 개수는 유지하고 새 강조만 해제해. 첫 도입, 날짜 변경, 앱 재실행, 동기화, 중복 수렴, 오늘로 이동 후 재이월의 의미를 계획대로 처리해. 새 작업 안내와 기존 이월·완료·오류 안내가 충돌하지 않게 해.
2. 기록 화면 안에 `활동 기록 / 회고` 탭을 추가해. 회고 탭은 내용 있는 기존 회고만 날짜 역순으로 보여주고, 본문·사진 중심 카드에서 전체 읽기·수정·회고 작성·이날 활동 보기로 이어지게 해. 사진이나 기분·날씨만 있는 회고도 보존하고, 빈 회고와 작업만 있는 날짜는 제외해. 탭별 검색·기간·목록 위치를 유지해.
3. 잠금 화면의 실시간 카드는 오늘의 ‘할 일’ 또는 ‘진행 중’ 작업이 하나라도 있으면 활성화하고, 둘 다 없어지면 사라지게 해. 처음부터 할 일만 있어도 시스템이 허용하는 실행 시점에 카드를 생성해. 할 일 카드에는 ‘시작’, 진행 중 카드에는 ‘완료’ 버튼을 제공하고, 변경 버튼으로 남은 할 일과 진행 중 작업을 상태 변경 없이 둘러보게 해. 시작은 선택한 작업만 진행으로 바꾸고, 완료 후 다른 작업이 남으면 같은 카드를 다음 작업으로 갱신해. 정적 위젯 설치나 선행 진행 전환을 요구하지 마. 기존 완료 확인·연속 입력 보호·Focus를 유지해. 관찰 가능한 수명 만료는 복구하되 ActivityKit이 원인을 알려주지 않는 사라짐은 당일 사용자 해제로 보수적으로 처리하고, iOS의 Activity 수명·시작 제약을 지키면서 앱 재활성화 등 허용 시점에 복구해. 시스템 한계를 넘는 무기한 백그라운드 유지는 약속하지 마.

PlanBase의 공통 테마, 버튼, 접근성, iPad 목록/상세 분할과 Mac 콘텐츠 폭에 맞춰 구현해. 공통 규칙과 조회 세션을 재사용하고, 회고 목록을 만들기 위해 전체 Task·진행·집중 이력을 불필요하게 조회하지 마. 로컬 확인 상태 때문에 배포 스키마나 CloudKit 모델을 변경하지 마.

이월함 → 회고 탭 → 잠금 화면 작업 선택 보완 → 실제 화면 점검 → 회귀 검증 순서로 진행해. 일반적인 구현·디자인 판단은 계획과 기존 패턴에 따라 해결하고, 계획만 다시 제시한 채 멈추지 마. 핵심 의미나 데이터 안전에 영향을 주는 결정만 필요한 최소 정보로 확인해.

검증은 격리된 로컬/메모리 저장소와 테스트 전용 앱에서 진행해. iCloud Drive 금지 경로, `.local/backups/`, 운영 사용자 데이터에 접근하거나 영향을 주지 마. 실제 CloudKit을 켠 일반 앱 실행으로 테스트하지 마.

관련 규칙·세션 테스트와 iPhone·iPad·Mac의 핵심 흐름을 확인해. 좁은 화면, 큰 글자, 밝은/어두운 테마, 접근성, 기존 칸반·이월·활동 기록·회고 저장/취소도 점검해. 최종적으로 `./scripts/verify-platform-builds.sh`를 통과시켜. 실패나 화면 결함이 발견되면 수정하고 해당 검증을 다시 실행해. 실행하지 못한 항목을 통과로 기록하지 마.

계획의 완료 조건을 모두 만족했을 때 Goal을 완료 처리해. 결과는 `docs/plans/active/CARRYOVER_AND_REVIEW_DISCOVERY_RESULTS.md`에 기록하고, 로그·스크린샷·검증 당시 소스 기준은 `.local/carryover-review-discovery/`에 보관해. 마지막에는 실제 변경 사항, 검증 결과, 남은 제한과 문서 링크를 한국어로 간결하게 알려줘.

이번 Goal 범위는 위 세 항목과 필요한 검증까지야. Dynamic Island 디자인 개선·Mac 메뉴 막대 타이머·Watch 기능 확장, 새 TestFlight 업로드·push·버전 증가는 포함하지 마. 잠금 화면 수정을 위한 공통 Live Activity 상태·Intent 변경과 다른 표시 영역에 대한 최소한의 상태 정합성·회귀 확인은 포함해.
