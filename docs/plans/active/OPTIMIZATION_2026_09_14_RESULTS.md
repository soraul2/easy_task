## 이번 변경

| 파일 | 변경 | 유지한 의미 |
|---|---|---|
| `TemplateListRules.swift` | 빈 검색에서는 항목 검사를 생략. 검색할 때는 전체 항목을 한 번만 읽어 일치하는 루틴 ID 집합을 구성 | 즐겨찾기 정렬, 검색 중 전체 범위 검색, 동일 이름의 입력 순서, 논리 ID가 같은 물리 레코드 유지 |
| `SavedTaskShortcutRules.swift` | 후보별 입력어 정규화와 정확 일치 여부를 한 번 계산하고 정렬에 재사용 | 정확 일치→즐겨찾기→제목→ID 순서, Unicode 및 잘못된 입력어 처리. 정확 일치 실행·모호성 오류 처리는 그대로 |
| `TemplateApplicationRules.swift` | 작업을 한 번 읽어 선택 날짜별 제목 집합을 구성. 개수 계산에 필요 없는 초안 정렬 생략 | 전체 개수에는 중복 초안 포함, 신규 개수에는 중복 제거. 날짜 중복·공백·대소문자·보관/대체 레코드 처리 유지 |

모든 보조 집합은 함수 호출 안에서만 유지한다. 장기 캐시를 추가하지 않아 편집·동기화 후
무효화 누락 가능성을 늘리지 않는다. 루틴별 항목을 실제 순서대로 반환하는 공개 함수는 유지한다.

## 검증과 남은 한계

변경 전 기존 관련 테스트 29개 통과. 시작 시 구현을 보존한 기준 함수와의 결과 비교에
즐겨찾기/전체 검색, 같은 이름의 순서, superseded 레코드, 논리 ID 중복,
편집 직후 재검색, 한글 조합형·분해형, 잘못된/중복 입력어, 빈 초안, 날짜 중복을 포함한다.
변경 후 기존 검사와 새 결과 비교 검사 3개를 합친 32개가 Debug에서 통과했다.

최초 기준 검사 실행은 새 테스트가 임시 `ModelContainer`를 유지하지 않아 종료됐다.
저장소 수명을 테스트 전체로 보장하도록 수정한 뒤 위 검사가 통과했다.
성능 기준선은 다른 검사와 분리해 별도로 완료한 실행만 사용한다.
